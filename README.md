# MVZ Consultoria – página institucional

```
mvz-consultoria/
├── index.html
├── css/style.css
├── js/main.js
└── assets/img/
    ├── logo.svg · logo-claro.svg · favicon.svg
    └── fundador.jpg   (adicionar)
```

## Antes de publicar
1. `js/main.js`: trocar `WHATSAPP` pelo número real.
2. `index.html`, seção Sobre: adicionar `assets/img/fundador.jpg` e confirmar o nome.
3. Trocar o logo provisório pelo arquivo oficial (PNG/SVG) em `assets/img/`.
4. Revisar textos de serviços.

Para visualizar, abra `index.html` no navegador. Para publicar, envie a pasta inteira para a hospedagem.
